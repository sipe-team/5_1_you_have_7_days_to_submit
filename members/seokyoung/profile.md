# 자기소개 — 고석영

## 소개
> 음악 듣는 걸 좋아하는 프론트엔드 개발자입니다. 최근에는 수영도 아주 좋아합니다.

## 기술 스택
| 영역 | 스택 |
|------|------|
| 주력 언어 | TypeScript |
| 프론트엔드 | Next.js, React, React Native |
| 백엔드 | Node.js, Express |
| 배포 환경 | Vercel |
| AI 도구 | Claude Code |

## 이 미션에서 이루고 싶은 것
- 상황별로 적절한 AI Orchestration 설계 방식
- 자동화에서 수집하는 데이터를 어떤 기준으로 어느 정도까지 정제해야 할지 알고 싶다. (업무는 어느 정도 기준이 쌓이는데, 음악 취향 등의 개인 성향이 짙은 데이터는 감이 잘 안 온다.)
- 취미에 도움이 되는 앱을 1개 출시해보고 싶다. (아마 수영 관련이 될 듯)

- 웹 서비스 배포 경험: 있음
