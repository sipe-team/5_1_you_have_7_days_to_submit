# md-fitter

## 한 줄 소개
> 마크다운을 던지면 A4 인쇄에 맞게 피팅해주는 브라우저 편집기.

## 문제 정의
노션에서 쓴 문서를 인쇄하려고 PDF로 내보내면 페이지가 지저분하게 끊긴다. 섹션 제목만 페이지 끝에 남거나, 리스트가 항목 중간에서 잘리는 식. A4 한 페이지에 맞추려면 결국 폰트 사이즈랑 간격을 계속 조정하면서 내보낸 pdf를 다시 확인하는 루프를 돌게 되는 경험이 종종 있었다.

노션도 하나의 마크다운의 형태이니 이미 마크다운으로 써둔 이력서를 그대로 붙여넣으면 A4에 알아서 맞춰주는 도구가 있으면 좋겠다 싶어서 만들었다.

## 기술 스택
| 영역 | 선택 | 선택 이유 |
|------|------|----------|
| 프론트엔드 | React 19 + Vite + TypeScript, Tailwind CSS | SPA로 가볍게 구성. 스타일링보다 텍스트 레이아웃을 정확히 잡는 게 핵심이라, Tailwind로 빠르게 마크업하고 미세 조정에 시간을 더 쓰는 쪽을 택함 |
| 백엔드 | 없음 (클라이언트 전용) | 이력서 데이터를 서버에 올릴 이유가 없음. Zustand + localStorage persist로 저장 |
| 배포 | Vercel / 정적 호스팅 | 서버 없이 충분. 번들 126KB (gzip, 500KB 제한의 25%) |
| AI 활용 | Planner → Coder → Reviewer 워크플로우 / Phase별 완료 로그 자동 생성 | 접근 권한을 계층 분리(읽기/src만/읽기)해서 에이전트가 스코프 밖으로 새는 걸 구조적으로 차단 |

### 핵심 기술 선택
- **pretext (@chenglou/pretext)**
    - DOM-free 텍스트 측정. (사실 이걸 써보고 싶어 만들게 된 것도 있다.) 
    - pretext는 `prepare()`와 `layout()`을 분리해서 호출할 수 있다. `prepare()`는 텍스트가 바뀔 때만, 리사이즈나 파라미터 변경 시엔 `layout()`만 다시 돌리는 규칙으로 리렌더 비용을 줄였다.
- **페이지 분할 규칙** 
    - (1) 섹션 제목이 페이지 끝에 혼자 남는 케이스 차단
    - (2) 아이템 제목과 첫 bullet은 같은 페이지에 고정
    - (3) 리스트가 단독으로 떨어져 있는 상황 방지
    - (4) `<!-- pagebreak -->` 수동 브레이크 지원
