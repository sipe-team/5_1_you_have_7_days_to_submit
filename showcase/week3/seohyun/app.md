# mobum.gg

## 한 줄 소개
> 전적 수정/삭제, 다국어, 내부 게임(룰렛·사다리타기)을 추가한 mobum.gg 고도화

## 문제 정의
초기 MVP 이후 실사용하며 느낀 불편함 해소.
전적을 수정·삭제할 수 없어 실수 시 대응이 어려웠고,
외부 게임 링크 대신 참가자 목록이 연동된 내부 게임이 필요했음.

## 링크
- 서비스: https://mobum-gg-g8d1.vercel.app

## 기술 스택
| 영역 | 선택 | 선택 이유 |
|------|------|----------|
| 프론트엔드 | React + TypeScript + Vite | 앱인토스 표준 스택 |
| 백엔드 | Supabase | 기존 구조 유지 |
| 배포 | Vercel | 기존 구조 유지 |
| AI 활용 | Claude Code + Cursor | 룰렛·사다리 게임 로직 구현 |
