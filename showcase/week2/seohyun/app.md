# mobum.gg

## 한 줄 소개
> 커피 내기 승패와 손익을 링크 공유만으로 기록하는 웹 서비스

## 문제 정의
입사동기들과 함께 사용하기 위해 개발했습니다.
  커피 내기 결과를 매번 채팅창에 적거나 기억에 의존해야 하지 말고,
  별도 가입 없이 방을 만들고 링크만 공유하면 누구나 전적과 손익을 확인할 수 있는 도구.

## 링크
- 서비스: https://mobum-gg-g8d1.vercel.app

## 기술 스택
| 영역 | 선택 | 선택 이유 |
|------|------|----------|
| 프론트엔드 | React + TypeScript + Vite | 앱인토스 표준 스택 |
| 백엔드 | Supabase | 실시간 동기화 + 빠른 프로토타이핑 |
| 상태관리 | Zustand | 가볍고 단순한 전역 상태 |
| 배포 | Vercel | GitHub 연동 간편 배포 |
| AI 활용 | Claude Code + Cursor | DB 스키마 설계 및 쿼리 작성 |
