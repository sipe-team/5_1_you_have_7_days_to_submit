# WOL - Wake on LAN — 회고

## 스펙 판단
- 넣으려다 뺀 기능: iCloud 동기화, Siri Shortcuts 연동, AI 진단 어시스턴트
- 빼서 다행인 기능: iCloud 동기화 — 로컬 저장소만으로 MVP에 충분했고, 동기화 디버깅에 이틀은 잡아먹었을 것
- 넣었는데 후회한 기능: 트러블슈팅 가이드 UI — MVP에서는 없어도 되는데 시간을 꽤 썼다

## 효율 돌아보기
- 이렇게 했으면 더 빨랐을 것: Watch 앱을 V2로 미루고 iPhone만 먼저 출시했으면 이틀 절약 가능했다
- AI 활용에서 효과적이었던 점: Monday Spec 문서 체계를 Claude Code로 한 번에 잡아서 스펙 정리 시간 단축
- AI 활용에서 비효율적이었던 점: Liquid Glass 스타일링을 AI에 맡겼다가 iOS 26 API 변경분을 반영 못 해서 수동 수정 - 스킬로 개선
