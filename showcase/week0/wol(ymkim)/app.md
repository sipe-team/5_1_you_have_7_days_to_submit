# WOL - Wake on LAN

## 한 줄 소개
> iPhone + Apple Watch에서 매직 패킷을 보내 PC를 원격으로 깨우는 앱

## 문제 정의
기존 WOL 앱들은 UI가 투박하거나 Watch 지원이 없어서, Liquid Glass 디자인에 Watch 컴패니언까지 갖춘 앱을 직접 만들기로 했다.

## 링크
- 앱스토어 링크 준비중 (심사중)

## 기술 스택
| 영역 | 선택 | 선택 이유 |
|------|------|----------|
| 프론트엔드 | SwiftUI (Liquid Glass) | iOS 26 디자인 시스템을 직접 써보고 싶었음 |
| 백엔드 | 없음 (로컬 저장소) | 서버 필요 없는 유틸리티 앱 |
| 배포 | App Store | 네이티브 앱이라 앱스토어가 유일한 루트 |
| AI 활용 | Claude Code로 도메인 모듈 설계, Stitch로 화면 생성 | 모듈 구조 잡기와 UI 프로토타이핑에 활용 |
