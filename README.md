# 납기까지 7일 — 매주 출하합니다

> 매주 1개의 애플리케이션을 실제로 런칭합니다.
> 웹앱이든 네이티브 앱이든, 카피 코딩이든 본인 아이디어든 상관없어요.
> 중요한 건 **"이번 주에 뭐 냈어?"** 라는 질문에 답할 수 있는 것.

## 미션 목적

AI 도구들이 코드 생성은 잘 해주는데, 앱을 완성해서 세상에 내놓는 경험은 도구가 대신 못 해줍니다.

이 미션은 AI를 단순히 코드 짜는 보조가 아니라, **작업 파이프라인 전체를 오케스트레이션하는 방식**으로 활용하면서 매주 실제 런칭까지 해보는 게 핵심입니다.

- **AI를 백그라운드 워커로 쓰는 구조 설계** — 코드 생성, 유즈케이스 검증, 폴리싱까지 AI에게 빠른 판단을 맡기고, 본인은 오케스트레이션에 집중
- **7일 안에 심사 등록까지** — 반복하면서 일의 비중을 조절하고, 오버 엔지니어링을 경계하는 감각 기르기
- **실패해도 다음 납기가 온다** — 못 낸 프로젝트는 접근 방향을 바꿔서 다시 도전. 매주 빠르게 회고하고 반복

## 참여 대상

- 만들고 싶은 거 많은데 항상 기획 단계에서 멈추는 분
- AI 도구를 "코드 생성기"가 아니라 "작업 파이프라인"으로 써보고 싶은 분
- 앱스토어/플레이스토어 출시 경험을 빠르게 쌓고 싶은 분
- 완벽주의 때문에 사이드 프로젝트를 끝낸 적이 없는 분

## 일정 (6주 = 2사이클)

한 사이클은 **2주 출하 + 1주 회고**로 구성됩니다.

| 주차 | 유형 | 내용 |
|------|------|------|
| **1주차** | 출하 | 첫 번째 앱 — 스펙 정리 → 피드백 → 구현 → 출시 → 회고 |
| **2주차** | 출하 | 두 번째 앱 — 스펙 정리 → 피드백 → 구현 → 출시 → 회고 |
| **3주차** | 회고 | 사이클 1 전체 회고 — 시간 배분, AI 활용도, 오버엔지니어링 점검 |
| **4주차** | 출하 | 세 번째 앱 — 스펙 정리 → 피드백 → 구현 → 출시 → 회고 |
| **5주차** | 출하 | 네 번째 앱 — 스펙 정리 → 피드백 → 구현 → 출시 → 회고 |
| **6주차** | 회고 | 사이클 2 전체 회고 — 전체 미션 회고 및 다음 방향 설정 |

> 사이클은 필요에 따라 연장할 수 있습니다. n사이클째에도 동일한 구조를 반복합니다.

## "7일이면 뭘 만들어요?"

풀타임으로 작업하지 않는 이상, 7일은 짧습니다. **그게 포인트입니다.**

7일 안에 낼 수 있으려면 스펙을 깎아야 합니다. "이것도 넣고 싶은데"를 참고 핵심만 남기는 판단이 필요합니다. 직장 다니면서 퇴근 후 시간, 주말 시간을 어떻게 배분할지 조율하는 것도 이 미션의 목표입니다.

매주 간단한 스펙 정리를 공유하고, 서로 **"이건 빼도 되지 않나?"** 피드백을 주고받는 시간을 가집니다.

## 배포 환경

본인에게 맞는 루트 하나에 집중하면 됩니다.

| 루트 | 추천 환경 | 비고 |
|------|----------|------|
| 웹앱 | Vercel, Netlify, Cloudflare Pages | 무료 플랜으로 충분. 가장 빠른 루트 |
| 네이티브 앱 | Play Store ($25, 1회) / App Store ($99/년) | 심사 기간 있으니 미리 등록 |
| 백엔드 필요 시 | Oracle Cloud Free Tier, GCP Free Tier, Firebase | 과금 폭탄 피하는 설계도 함께 고민 |

배포 환경 선택 자체도 좋은 공유 주제가 됩니다.

## 패널티 — "고객이 되어주기"

이 미션에서 가장 무서운 벌칙은 벌금이 아니라, **내 앱에 진짜 사용자 피드백이 달리는 것**입니다.

| 상황 | 패널티 |
|------|--------|
| 출시 성공 | 없음 |
| 미출시 (1회) | 다른 멤버 앱 1개를 실사용 + PR에 **사용 후기 300자 이상** 작성 |
| 미출시 (2회 연속) | 다른 멤버 앱 **전부** 사용 후기 작성 + 모임에서 **실패 회고 발표 5분** |
| 중도 포기 | 모든 멤버 앱에 유료 결제 또는 스토어 리뷰 작성 |

> 미출시자의 패널티가 다른 멤버에게는 **실제 사용자 피드백**이라는 보상이 됩니다.
